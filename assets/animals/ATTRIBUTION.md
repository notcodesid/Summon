## Why this needs your attention

Creative Commons licences differ. Most Flickr CC licences require
**attribution to the photographer**, and some are non-commercial only, which
would not cover a released app. loremflickr does not return the photographer
or the specific licence alongside the image, so the attribution required for
each file is **not recorded here**.

Two clean ways to resolve it:

1. **Replace them with your own photos.** Drop new files in this folder using
   the same names — no code change needed.
2. **Buy or licence a set** and swap them in the same way.

Requirements if you replace them: square, roughly 300×300, subject's face
centred (the image is masked to a circle, so the edges are cut off).

Wikimedia Commons was tried first, but `upload.wikimedia.org` returns 403 to
this environment, so it could not be used as a source.
