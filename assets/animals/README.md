# Animal photos for the sign-in hero

Drop square-ish photos here, then list them in `lib/animal-images.ts`.

- **Format:** `.jpg` or `.png`
- **Size:** 300×300 is plenty — they render at ~75pt inside a circle
- **Framing:** the animal's face centred, since the image is masked to a circle
  and the edges get cut off
- **Naming:** lowercase, one animal per file — `dog.jpg`, `cat.jpg`, `cow.jpg`

Ten photos fills the cluster with no repeats. Fewer works too — the remaining
orbs fall back to icons.

Anything you add must be yours or licensed for use in the app.
